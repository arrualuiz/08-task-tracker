Ative o acesso às suas tarefas

  1. Ative a Google Tasks API no projeto Task Tracker.
  2. Clique em Autorizar Google Tasks, escolha a conta e permita a leitura das tarefas, calendários e eventos.
  3. Repita para as outras contas que quiser consultar. A configuração JSON já salva é reaproveitada.

Se ainda não configurou o Google neste computador, comece em Calendários.
